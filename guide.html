Virtual Card Nepal Deployment

1. Supabase

  1. Create a Supabase project.
  2. Run supabase-schema.sql in SQL Editor.
  3. Create the admin email/password under Authentication → Users.
  4. Use the project URL and anon key for Vercel; use the service-role key only on Render.

2. Render backend

  1. Build: npm install && npm run build
  2. Start: npm start
  3. Add SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, ADMIN_EMAIL, SUPABASE_STORAGE_BUCKET, and FRONTEND_URL.

3. Vercel frontend

  1. Import the same repository.
  2. Framework: Next.js.
  3. Add NEXT_PUBLIC_API_URL, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, and NEXT_PUBLIC_ADMIN_ROUTE_PATH.

4. Domain

Point the custom domain to Vercel. Keep the Render service URL as the API URL. If you later want api.yourdomain.com, add that subdomain to Render and update NEXT_PUBLIC_API_URL.
